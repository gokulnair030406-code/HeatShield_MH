MODEL TRANSPARENCY

What this dashboard is (and isn't)

HeatShield uses a dense neural network to estimate a heat-vulnerability proxy from seven inputs. The bundled Maharashtra dataset and target labels are formula-generated proxy labels for demonstration. It is not a real-time government warning service.
