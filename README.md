# HeatShield MH — Previous Premium Design, Single Vulnerability Dataset

This build restores the previous HeatShield MH dashboard design and uses **only** `data/maharashtra_vulnerability.csv`. The old `maharashtra_heat_demo.csv` and original heat-risk model pipeline are removed.

## Run
```powershell
pip install -r requirements.txt
python app.py
```
Open http://127.0.0.1:5000.

## Model
7 inputs → Dense(32, ReLU) → Dropout(0.10) → Dense(16, ReLU) → Dense(1, Sigmoid × 100). Adam optimiser, MSE loss and backpropagation.

## Spatial predictions
The 34 CSV locations are the only source stations. Other locations are estimated by IDW interpolation of the six supplied numeric environmental variables; aridity proxy is derived after interpolation, then the seven features are scored by the neural network.

## Transparency
The HVI labels are generated by a documented weighted formula and are **proxy labels**, not measured or official vulnerability scores. Metrics describe agreement with those generated labels only.
